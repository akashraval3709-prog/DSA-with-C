# DSA with C - Bubble Sort

This repository contains an optimized version of the **Bubble Sort** algorithm.

### Key Features:
- **Optimized with Flag:** Uses an `exchs` variable to detect if the array is already sorted, preventing unnecessary passes.
- **Efficient Range:** Reduces the comparison limit in each pass using `last--`.

### How to Run:
1. Copy the code into a C compiler (like VS Code with GCC or Turbo C++).
2. Compile and run.
3. Enter the number of elements and the values to see the sorted output.
